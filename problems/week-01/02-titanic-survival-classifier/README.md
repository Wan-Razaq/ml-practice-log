**Difficulty:** Easy
**Week:** 1
**Date:** 2026-09-23
**Dataset/Source:** [Kaggle Titanic - Machine Learning from Disaster](https://www.kaggle.com/c/titanic/data) (`train.csv`)

## Problem

Predict whether a passenger survived the Titanic disaster (binary: 0/1) from features like passenger class, sex, age, fare, and number of siblings/parents aboard. Train a logistic regression classifier (sklearn) on `train.csv`, with a held-out validation split. Success metric: accuracy (and take a look at precision/recall too, since survival isn't perfectly balanced).
